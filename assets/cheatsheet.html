Cheatsheet1.0 — session, domains, tools, bench

Powerful. Precise. Honest.

1 Open a session

  • trek in the project. Memory and the reflective loop are on.
  • --memory off --effort off|normal|loose
  • --operator-mode supervised delegated checkpoint diagnostic ask
  • --debug or TREK_DEBUG=1 → ~/.trek/agent/trek-debug.log (secrets redacted).
  • TREK_NO_LOCAL_LLM=1 uses the API model. PI_NO_LOCAL_LLM still accepted.
  • Factory single: one Workhorse. /hierarchy sets single, auto, or manual.
  • /login /model /new /quit. Enter sends. Prompt stays when Working... starts.
  • In your shell: set -o vi for vi line editing (operator only; not a trek tool).

2 One turn

  • The words in the turn choose the domain. A menu does not.
  • Workflow runs one Archon node at a time. A prompt node does not call a tool.
  • Write/edit/update/replace plus a filename → no domain workflow; the tool loop runs.
  • Fix, push, blocked, or “what is happening” → tools, not a workflow.
  • Short one-shot shell prompts (mkdir, sum, trim, …) classify as Act when bash is available.
  • Same model on Workhorse and Planning → no extra planning brief.
  • A fact not in the turn is said to be not in the turn. Empty upstream reply is (none).

3 Domains & science

Twenty domains. Meta, AI, Security, Engineering stay on. Science can be off.

  • /domains /domains enable finance /domains disable finance
  • /workflows show finance prints the DAG. It does not run it.
  • Science workflows (see domains/science/domain.json):
method-check write-paper review-paper-coauthor review-paper-referee respond-to-reviews write-rebuttal generate-slides generate-poster polish-bibtex check-latex-build figure-pass extract-claims write-abstract
  • Leakage / train-test holds apply only for method-check.

4 Lessons & patterns

  • Failed turn, or correction starting with No., may store one lesson in that domain.
  • /lessons /lessons finance — id, category, area, severity, count, status.
  • /crystallize <id> writes a skill only after Yes, only for that domain.
  • Patterns: .trek/domains/<id>/lessons.yaml. Bundled file stays as shipped.
  • /patterns /patterns edit finance categories add tax_gap /patterns restore finance
  • Keys and private keys refused everywhere. Finance drops account numbers. Cross-domain recall rules apply.

5 Edit & branches

  • Three-line edit: first non-empty line unique, match key ≥12 chars; third non-empty line exactly two file lines below the first; middle may differ.
  • Match keys trim indent, collapse spaces, treat ' as ". Blank lines inside oldText are not counted.
  • spawn_branches (≤4 subtasks) + gather. First branch to write a path owns it.
  • Bench fan-headings: one spawn_branches, one branch per file, no edit in the parent turn.

6 Bench & debug

  • trek bench run — checked-in pack, no model. Not trek models benchmark.
  • trek bench run --live needs XAI_API_KEY or .env.
  • --profile same|climb|fan --lever single|auto|both --task id --timeout ms
  • same: grok-4.3 every role. climb: floor vs floor+grok-4.7 Planning/Frontier.
  • fan: grok-4.7 alone vs grok-4.7 Planning + grok-4.20-0309-non-reasoning Workhorse (--lever auto).
  • Debug log redacts --api-key, --token, --password, --secret, Bearer, and sk- / ghp_ / hf_ shapes.
