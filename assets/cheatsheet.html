CheatsheetThe session, the domain, the lesson.

Powerful. Precise. Honest.

1 Open a session

  • trek in the project. Memory and the reflective loop are on.
  • TREK_NO_LOCAL_LLM=1 uses the API model. PI_NO_LOCAL_LLM is still accepted.
  • /login /model /new /quit
  • Enter sends. The prompt stays in the transcript when Working... starts.

2 One turn

  • The words in the turn choose the domain. A menu does not.
  • The workflow runs one node at a time. A prompt node does not call a tool.
  • The next node receives the earlier reply. An empty reply is (none).
  • A fact that is not in the turn is said to be not in the turn.
  • A request to fix or push does not start the review. The session uses tools.

3 Domains

Twenty domains. Four stay on: Meta, AI, Security, Engineering.

  • /domains lists them. /domains enable finance /domains disable finance
  • /workflows show finance prints the steps. It does not run them.
  • Detection still chooses the workflow on the next prompt.

4 Lessons

  • A failed turn, or a correction that starts with No., may store one lesson.
  • The lesson takes the domain of that turn: category, area, before, and after.
  • /lessons /lessons finance shows id, category, area, severity, count, status.
  • /crystallize <id> writes a skill only after you confirm, and only for that domain.

5 Patterns

Edits go to .trek/domains/<id>/lessons.yaml. The bundled file stays as it shipped.

  • /patterns /patterns finance
  • /patterns edit finance categories add tax_gap
  • /patterns edit finance targets add sox-memo SOX memo
  • /patterns edit finance never add west-cistern
  • /patterns restore finance steps back one edit.

6 Never stored

  • Keys and private keys are refused in every domain.
  • A finance lesson also drops an account number.
  • A lesson that still matches is not stored.
  • A finance lesson is not recalled on a robotics turn. Meta, AI, Security, and Engineering may be.
