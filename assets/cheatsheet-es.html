Hoja de referencia1.0 — sesión, dominios, herramientas, bench

Potente. Preciso. Honesto.

1 Abrir una sesión

  • trek en el proyecto. La memoria y el bucle reflexivo están activos.
  • --memory off --effort off|normal|loose
  • --operator-mode supervised delegated checkpoint diagnostic ask
  • --debug o TREK_DEBUG=1 → ~/.trek/agent/trek-debug.log (secretos redactados).
  • TREK_NO_LOCAL_LLM=1 usa el modelo de API. PI_NO_LOCAL_LLM sigue valiendo.
  • De fábrica single: un Workhorse. /hierarchy fija single, auto o manual.
  • /login /model /new /quit. Enter envía. El prompt sigue cuando empieza Working...
  • En tu shell: set -o vi para edición vi (solo el operador; no es una herramienta de trek).

2 Un turno

  • Las palabras del turno eligen el dominio. Un menú no.
  • El flujo corre un nodo de Archon por vez. Un nodo de prompt no llama una herramienta.
  • Write/edit/update/replace más un archivo → sin flujo de dominio; corre el bucle de herramientas.
  • Fix, push, blocked o “what is happening” → herramientas, no un flujo.
  • Un shell corto de un paso (mkdir, suma, recorte, …) se clasifica como Act si hay bash.
  • El mismo modelo en Workhorse y Planning → sin brief de planificación extra.
  • Un dato que no está en el turno se declara ausente. Una respuesta vacía es (none).

3 Dominios y ciencia

Veinte dominios. Meta, AI, Security y Engineering siguen activos. Science puede estar apagado.

  • /domains /domains enable finance /domains disable finance
  • /workflows show finance imprime el DAG. No lo ejecuta.
  • Flujos de Science (ver domains/science/domain.json):
method-check write-paper review-paper-coauthor review-paper-referee respond-to-reviews write-rebuttal generate-slides generate-poster polish-bibtex check-latex-build figure-pass extract-claims write-abstract
  • Fuga y train-test valen solo para method-check.

4 Lecciones y patrones

  • Un turno fallido, o una corrección que empieza por No., puede guardar una lección en ese dominio.
  • /lessons /lessons finance — id, categoría, área, severidad, cuenta, estado.
  • /crystallize <id> escribe una skill solo después de Yes, y solo en ese dominio.
  • Patrones: .trek/domains/<id>/lessons.yaml. El archivo empaquetado queda como se entregó.
  • /patterns /patterns edit finance categories add tax_gap /patterns restore finance
  • Claves y claves privadas se rechazan siempre. Finance descarta números de cuenta. Vale el recuerdo entre dominios.

5 Edición y ramas

  • edit de tres líneas: la primera línea no vacía es única y la clave tiene ≥12 caracteres; la tercera línea no vacía está exactamente dos líneas de archivo bajo la primera; el medio puede diferir.
  • Las claves recortan la sangría, colapsan espacios y tratan ' como ". Las líneas en blanco dentro de oldText no cuentan.
  • spawn_branches (≤4 subtareas) + gather. La primera rama que escribe una ruta es la dueña.
  • Bench fan-headings: un spawn_branches, una rama por archivo, sin edit en el turno padre.

6 Bench y depuración

  • trek bench run — paquete incluido, sin modelo. No es trek models benchmark.
  • trek bench run --live necesita XAI_API_KEY o .env.
  • --profile same|climb|fan --lever single|auto|both --task id --timeout ms
  • same: grok-4.3 en cada rol. climb: piso contra piso+grok-4.7 en Planning/Frontier.
  • fan: grok-4.7 solo contra grok-4.7 en Planning + grok-4.20-0309-non-reasoning en Workhorse (--lever auto).
  • El log de depuración redacta --api-key, --token, --password, --secret, Bearer y formas sk- / ghp_ / hf_.
